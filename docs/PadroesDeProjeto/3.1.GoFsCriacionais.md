## Issue #1 - Factory Method (Criacional)

### Descrição

Implementar o padrão **Factory Method** para centralizar a criação de inimigos. Em vez de instanciar `PackedScene` espalhado pelo código, uma única função de fábrica recebe um tipo e retorna a cena correta já configurada.

### O que foi feito

| Atividade | Detalhamento |
|-----------|--------------|
| **Arquivo criado** | `scripts/enemies/enemy_factory.gd` |
| **Arquivo criado** | `scenes/enemies/enemy_ranged.tscn` |
| **Arquivo modificado** | `scripts/world/room_validator.gd` |

### Funcionamento

# Antes: instanciação direta (espalhada pelo código)
var enemy = load("res://scenes/enemies/enemy.tscn").instantiate()

# Depois: centralizado na fábrica
var enemy = EnemyFactory.create(&"basic")
var ranged = EnemyFactory.create(&"ranged")

### Tipos de inimigos suportados

| Tipo | Descrição | Arquivo |
|------|-----------|---------|
| `"basic"` | Inimigo básico | enemy.tscn |
| `"melee"` | Inimigo corpo a corpo | enemy_melee.tscn |
| `"ranged"` | Inimigo à distância | enemy_ranged.tscn |


### Evidência de funcionamento

Inimigo BASIC criado - Cor: (1.0, 0.0, 0.0, 1.0)
Inimigo RANGED criado - Cor: (0.94, 0.94, 0.04, 1.0)
Velocidades: Basic=60, Melee=80, Ranged=40

### Benefícios

Centralização: Toda criação de inimigos passa pela fábrica
Facilidade para evoluir: Adicionar novo inimigo = apenas adicionar no dicionário
Desacoplamento: Quem usa a fábrica não sabe detalhes do inimigo

# 3.2 Builder (Criacional)

### Descrição

Implementar o padrão Builder para montar salas de forma procedural passo a passo. Em vez de uma sala ser sempre idêntica, o Builder permite configurar: quantos inimigos, quais itens, qual tilemap, quais portas existem.

### O que foi feito

| Atividade | Detalhamento |
|-----------|--------------|
| Arquivo criado | `scripts/world/room_builder.gd` |
| Arquivo criado | `scripts/world/room_director.gd` |
| Arquivo modificado | `scripts/autoloads/game_manager.gd` |

### Estrutura

| Componente | Responsabilidade |
|-----------|------------------|
| RoomBuilder | Constrói salas passo a passo (adiciona inimigos, itens, portas) |
| RoomDirector | Fornece "receitas" pré-definidas (sala de combate, descanso, etc.) |

### Tipos de sala disponíveis

| Método | Descrição | Conteúdo |
|--------|-----------|----------|
| `build_combat_room()` | Sala de combate | Inimigos (varia com dificuldade) |
| `build_rest_room()` | Sala de descanso | Itens de cura, sem inimigos |
| `build_boss_room()` | Sala de chefão | Inimigos mais fortes |
| `build_empty_room()` | Sala vazia | Apenas estrutura, para testes |

### Benefícios

Reutilização: Mesmo builder cria diferentes tipos de sala
Flexibilidade: Fácil adicionar novos tipos de sala
Legibilidade: Código expressivo e fácil de entender

# 3.3  Object Pool - Pool de Projéteis

### Descrição

Implementar um pool de objetos para projéteis. Em vez de criar e destruir nós a cada disparo (instantiate + queue_free), o pool mantém um conjunto de projéteis inativos e os reutiliza.
