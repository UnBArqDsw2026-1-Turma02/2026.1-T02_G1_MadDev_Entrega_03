# 3.3.1 Template Method (Comportamental)

### Descrição

Implementar Template Method para definir o esqueleto do fluxo de ataque dos inimigos. A classe base define a ordem: can_attack() → prepare_attack() → execute_attack() → cooldown(). Cada inimigo sobrescreve apenas as etapas que diferem.

### O que foi feito

| Atividade | Detalhamento |
|-----------|--------------|
| Arquivo modificado | `scripts/enemies/enemy_base.gd` |
| Arquivo criado | `scripts/enemies/enemy_melee.gd` |
| Arquivo criado | `scripts/enemies/enemy_ranged.gd` |
| Arquivo criado | `scenes/enemies/enemy_melee.tscn` |

### Estrutura do Template Method

| Etapa | Quem implementa | Descrição |
|-------|-----------------|-----------|
| can_attack() | Pode sobrescrever | Verifica se pode atacar (distância, visão) |
| prepare_attack() | Opcional - sobrescrever | Prepara o ataque (animação, som, mira) |
| execute_attack() | Obrigatório - sobrescrever | Aplica o dano ao jogador |
| cooldown() | Padrão - raro sobrescrever | Inicia o tempo de recarga |

### Tipos de inimigos implementados

| Tipo | Comportamento de Ataque |
|------|------------------------|
| Basic | Ataque simples direto (usa implementação padrão) |
| Melee | Ataque corpo a corpo com preparação |
| Ranged | Ataque à distância com mira e projétil |
